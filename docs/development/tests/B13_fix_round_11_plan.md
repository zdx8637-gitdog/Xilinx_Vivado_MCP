## 1. F-25：lwIP NO_SYS 零窗口 persist 恢复缺陷（首要）

### 1.1 现象证据（报告1 §1.5 + 报告2 §2.2/§6）

- 溢出门禁排空在 35s 停读后停滞：DBG 实测 `sndwnd=65070`（窗口已重开）、
  `cwnd=1446`（1 MSS）冻结 75s、0 字节排出；
- 断连重连排空（新连接满 cwnd）尾部续传 255 行后仍停滞；
- 契约语义本身全部正确（丢最旧 + 溢出计数 40 + 尾连续 + 断连续传光标），
  缺陷定位在 lwIP 拥塞/持久计时器恢复层。

### 1.2 已排除项

- 去 `SO_RCVBUF=4096`（病态零窗口源，已移除，F-25c 前身）；
- 去 100ms RXEN 翻转工作区（ACK-only RX 不适用，已移除，F-25d）；
- 门禁层改判/断连重连（D1，已做，缓解未根治）。

### 1.3 修复阶梯（成本升序，来源：报告2 §6 四方向）

| 方向 | 内容 | 判断 |
|---|---|---|
| D1 | 门禁层改判 | 已做，不足以根治（排空 deadline 仍过不了） |
| D2 | lwIP 调参：开 `LWIP_WND_SCALE` 换宽窗口（消除 u16 窗口钳制，与 #3 同源），配 `TCP_SND_BUF`/`TCP_MSS`/`TCP_WND` 组合 | 低成本，先试 |
| D3 | 应用层排空看门狗：排空 stall 检测（有界超时）→ abort + 重连循环直至 END 送达 | 中成本，兜底 |
| D4 | lwIP persist/慢启动恢复路径打补丁或换版本 | 高成本，最后 |

**推荐：D2 + D3 组合**——先 D2 消除钳制因子（证据已证明 u16 钳制真实存在），
若 DBG 仍现 persist 冻结则 D3 看门狗保证 END 必达；D4 仅在 D2/D3 均证伪后启动。
