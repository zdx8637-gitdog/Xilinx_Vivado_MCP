# B12-A2 考题需求草案：AD7606C-16 采集与 UART 上行（DRAFT）

> 日期：2026-08-25 ｜ 状态：DRAFT（白盒用；黑盒冻结时以冻结基线为准）
> 目标切片：B12-A2 = FPGA 控制 AD7606C-16 完成采集，真实采样值经 UART 上行，供外部画波形与对账。

## 1. 目标（一句话）

在 AX7020 上验证 **FPGA 对 AD7606C-16 的完整控制链**：CONVST 触发转换 → BUSY 等待 → CS/RD 逐通道读 16 位数据 → PS 汇总 → UART 上行**真实采样值**（非状态行），外部可画波形复核。

## 2. 板卡物理事实（黑盒可见，来源=板卡包 `boards/ALINX_AX7020_v1.0/adc/`）

- 模块：凌智 AD7606C-16（16Bit@1MSPS_ADC V1.3），插 AX7020 **J11**；24 根信号线 LVCMOS33（引脚映射见 `adc_ad7606c_pinmap.json`，XDC 参考 `docs/boardinformation/ad7606c_j11.xdc` 仅白盒可用）；
- 供电：模块 +5V（J11 PIN2），板上自生成 VDRIVE=3.3V；
- 配置（用户已设）：**量程 J1 = ±10V 档**、基准 J3 = 内部 2.5V；
- 模块事实卡与 ADI 数据手册：`adc/ad7606c_module_facts.md`、`adc/ADI-ad7606c-16_cn_Rev.0.pdf`——时序与寄存器细节以数据手册为准；
- FPGA 侧初始化要求：STBY 置高、OS[2:0]=000（无滤波）、SER=0（并行）、RESET 按数据手册极性操作。

## 3. 目标行为（要什么）

1. **采集**：以**不低于 1 kHz 的采样率**（CONVST 门控）周期采集全部 8 通道（16 位二进制补码）；
2. **上行真实采样值**：经 PS UART（115200）上行采样值序列，格式可机器解析（行式 `t,ch,value` 或等价形式均可，由实现方自定并在 banner 中声明格式）；
3. **持续采集**：连续采集并上行**不少于 30 秒**的数据，随后可继续循环（不停机）；
4. **判定输出**：采集满时长且全程上行无误后打印一次 `A2_PASS`；任一环节失败（读时序失败/数据缺失/上行中断）打印 `A2_FAIL` 并停。

## 4. 盲测参数（用户持有答案，对账用）

- 8 个模拟通道中**恰有 1 路**接有正弦信号，其余悬空；
- 该**通道号**与**信号频率**均为盲测参数——**本需求及一切供给文档中均不出现**，必须由智能体从采集数据中自行测定；
- 智能体必须输出测量结论：有信号通道号、频率（Hz）、峰峰值（V，按 ±10V 量程换算）。

## 5. PASS/FAIL 判据（机读 + 外部对账）

| 条件 | 判定 |
|---|---|
| `A2_PASS`（一次）+ 采样值序列完整（≥30s） | 机读 PASS（evaluate_observation 显式 marker） |
| `A2_FAIL` / 无 marker（120s 超时） | FAIL / TIMEOUT |
| 外部对账（**solid 证据，由用户执行**）：波形图为正弦、测量频率与用户答案误差 ≤1%、通道号正确 | 用户终审 |

## 6. 不限定实现（智能体自主决策）

- 采集控制器形态（自定义 PL 模块/软核轮询）、PS 与 PL 的数据交接方式（AXI-Lite 寄存器/BRAM/FIFO）、通道识别算法（方差/幅度/FFT）、频率测量算法（过零/FFT）——均由实现方按 S3 选型决定；带宽受限时，识别出有信号通道后可仅上行该通道采样值，但识别依据必须来自全部 8 通道的采集数据。
