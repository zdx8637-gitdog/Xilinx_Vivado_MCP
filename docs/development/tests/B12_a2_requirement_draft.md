# B12-A2 考题需求：AD7606C-16 连续采集（PL 环形缓冲）+ UART 指令触发上行（DRAFT v2）

> 日期：2026-08-25 ｜ 状态：DRAFT v2（白盒用；黑盒冻结时以冻结基线为准）
> 目标切片：B12-A2 = FPGA 控制 AD7606C-16 连续采集入环形缓冲，PS 收到 UART 指令后上传最新固定时长全 8 通道原始采样值，外部保存数据并绘制 8 通道波形图对账。
> v2 变更（用户 2026-08-25 定）：采集与上行**解耦**（PL 环形缓冲、采集永不停机）；上行改为 **UART 指令触发**、数据量**固定 1 秒**、**全 8 通道**；新增**保存数据文件 + 8 通道「ADC 原始值 vs 时间」波形图**对账证据（原始值不换算电压）。

## 1. 目标（一句话）

验证 FPGA 对 AD7606C-16 的完整控制链，并实现**采集与传输解耦**：PL 侧周期触发 CONVST、读取 8 通道 16 位数据并**连续写入环形缓冲**（采集永不停机）；PS 侧收到 UART 指令后，从缓冲**拉取最新固定 1 秒的全 8 通道原始采样值上传**，上传完成即停止发送；测试方保存数据并绘制 8 通道波形图复核。

## 2. 板卡物理事实（黑盒可见，来源=板卡包 `boards/ALINX_AX7020_v1.0/adc/`）

- 模块：凌智 AD7606C-16（16Bit@1MSPS_ADC V1.3），插 AX7020 **J11**；24 根信号线 LVCMOS33 / BANK35（引脚映射见 `adc_ad7606c_pinmap.json`，XDC 参考 `docs/boardinformation/ad7606c_j11.xdc` 仅白盒可用）；
- 供电：模块 +5V（J11 PIN2），板上自生成 VDRIVE=3.3V；
- 配置（用户已设）：**量程 J1 = ±10V 档**、基准 J3 = 内部 2.5V；
- 模块事实卡与 ADI 数据手册：`adc/ad7606c_module_facts.md`、`adc/ADI-ad7606c-16_cn_Rev.0.pdf`——时序与寄存器细节以数据手册为准；
- FPGA 侧初始化要求：STBY 置高、OS[2:0]=000（无滤波）、SER=0（并行）、RESET 按数据手册极性操作。

## 3. 架构与目标行为

**架构（用户定，实现方必须遵守）：**

1. **采集（PL 侧，独立自跑）**：采样率**不低于 1 kHz**（实现方自定并声明，建议 2000 Hz）；PL 自己周期触发 CONVST、按数据手册时序读取全部 8 通道 16 位二进制补码，**连续不停写入 PL 侧环形缓冲**（BRAM 或等价 PL 资源；容量至少覆盖连续数秒）。采集循环**与 PS、与上行完全无关，永不停机**。
2. **上行（命令触发，PS 侧）**：PS 通过 UART（115200）打印 READY banner 后**等待指令**；测试方发送固定指令（文本，如 `UPLOAD`）后，PS 从环形缓冲**拉取最新固定时长 = 1 秒**的全 8 通道采样值上传；**上传数据量固定（FS×1s×8 通道），不是指令参数**；上传完成后打印 DONE 并**停止发送**，回到纯采集状态（不影响采集连续性）。
2.1 **快照必须为冻结副本（采集与传输彻底解耦，硬性）**：`UPLOAD` 触发后，被上传的 1s 数据必须**先冻结**——锁存时刻起其内容不再随后续采集变化。实现方式任选（如 PL 在锁存瞬间把 1s 数据拷入独立快照存储，或 PS 在采集追及前一次性读入内存），但**禁止在上传过程中直接读取正在被写入的环形缓冲地址**——写指针追及读指针会造成数据混帧、波形时间轴不连续、频率测量失真（实测教训：快照只锁基址不锁数据 → 上传 5.6s 期间写指针绕圈 2.7 次 → 波形截断、频率误读）。上传期间采集的继续写入**不得**改写或混入已冻结的快照内容。
3. **上传格式**：机器可解析，实现方自定并在 READY banner 中声明（采样率、帧结构、样本数、校验方式）；数据必须能逐样本定位通道与时间顺序；**必须含完整性校验（长度 + 校验和），校验失败或缺帧视为上传失败**。
3.1 **上传纪律（测试侧，硬性）**：为减少突发丢帧，**分批发送**（如每 256 帧一组、组间短延时）；测试方收到数据后立即校验，**校验失败或缺帧 → 停止捕获并重试**（有界次数）；**最终证据必须来自校验通过的完整捕获**（帧数 = FS×1s×8 通道，无缺帧）。
4. **保存与绘图（对账证据）**：测试方将**校验通过的完整上传数据**保存为文件（CSV 或等价），并绘制**全部 8 个通道的「ADC 原始值（不换算电压）vs 时间」波形图**（8 子图或分图均可），作为外部对账证据。
5. **判定输出**：上传完成且数据完整（数量/校验通过）后打印一次 `A2_PASS`；任一失败（等待超时/数据缺失/校验失败）打印 `A2_FAIL` 并停。

## 4. 盲测参数（用户持有答案，对账用）

- 8 个模拟通道中**恰有 1 路**接有正弦信号，其余悬空；
- 该**通道号**与**信号频率**均为盲测参数——**本需求及一切供给文档中均不出现**，必须由智能体从采集数据中自行测定；
- 智能体必须输出测量结论：有信号通道号、频率（Hz）、峰峰值（V，按 ±10V 量程换算）。

## 5. PASS/FAIL 判据（机读 + 外部对账）

| 条件 | 判定 |
|---|---|
| READY → 发送 UPLOAD → 收到 DONE + 数据量/校验通过 + `A2_PASS` 一次 | 机读 PASS |
| `A2_FAIL` / 指令无响应 / 数据缺失或校验失败 | FAIL |
| **等待纪律（硬性）**：所有串口等待必须有界且短（与固定 1s 上传数据量匹配，建议单次 ≤10s）；超时立即 `ps_stop_uart_capture` 后重试；禁止无兜底长等待占住执行通道 | 硬性要求 |
| 外部对账（**solid 证据，由用户执行**）：8 通道波形图为正弦/其余通道近 0、**波形时间轴连续（无混帧拼接/截断）**、测量频率与用户答案误差 ≤1%、通道号正确 | 用户终审 |

## 6. 不限定实现（智能体自主决策）

- 环形缓冲读接口（AXI BRAM 控制器 / GPIO 窗口 / 自定义接口）、帧格式、通道识别算法（方差/幅度/FFT）、频率测量算法（过零/FFT）、绘图实现——均由实现方按 S3 选型决定；通道识别依据必须来自全部 8 通道的采集数据；数据文件与波形图必须基于真实上传数据生成。
