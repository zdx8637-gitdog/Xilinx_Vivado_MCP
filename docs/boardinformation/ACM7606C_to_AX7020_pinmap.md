## 4. 与官方 AN706 的差异（说明）

ALINX AN706（AD7606 非 C 版）官方 XDC：OS1=PIN3/F17、OS0=PIN4/F16、CONVST=PIN5/F20、OS2=PIN6/F19、RD=PIN7/G20、RESET=PIN8/G19、BUSY=PIN9/H18、CS=PIN10/J18、FRSTD=PIN12/L19、DB0..15=PIN15..30（DB0=K18）。
本模块转接板为 J2 行序直连：**SER=PIN5、CONV=PIN7、STBY=PIN8、WR=PIN10**（AD7606C 新增控制脚，AD7606 无），数据总线每对 (奇|偶)（DB0=K17）。FPGA 设计按本表即可，无需兼容 AN706。

## 5. 使用要点 / 跳帽设置（已确认，原理图 J1/J3 实读）

**供电**：模块单 +5V 供电，由开发板 J11 PIN2（+5V）经转接板 → 模块 J2 的 +5V 行直接馈入（J11 PIN1=GND 同步接入），模块板上完成 5V→5.8V→5V/3.3V 生成，**无需外接电源**。模块左侧绿色双位端子为独立供电时的备用入口，接转接板时不用。

**量程**：J1 三针跳帽（输入模拟电压范围选择·硬件模式），中间脚=芯片 RANGE（pin8），**跳帽接 ±10V 侧（pin1–pin2）＝±10V 量程**；接 ±5V 侧（pin2–pin3）＝±5V。软件模式下量程由寄存器 RANGE 位决定，J1 失效（本工程用硬件模式，J1 生效）。
- ±10V：1LSB = 20V/65536 = 305.18µV；±5V：1LSB = 152.59µV。

**基准**：J3 五针跳帽（底部 GND，1 2 3 4 5）：
- **1–2 短接 = 内部基准**（默认推荐）：使用芯片内部 2.5V 带隙基准（REFIN/REFOUT 输出 2.5V，pin1=VDR 即内部基准输出脚）；
- **2–3 短接 = 外部基准**：改用外部 2.5V 基准源，须从 **pin4（VREF，外部基准输入）** 注入精密 2.5V；
- **pin5 = GND**（基准回路地）。
- 内部基准精度足够波形测量/实验学习；仅做高精度计量/多板一致标定时才需外部基准。

**输入**：8 通道差分/单端（V1+~V8+ / V1-~V8-，270R 限流 + ±21V 钳位）。正弦波建议单端接法：信号源 → V1+，信号源地 → V1-（或 V1- 与 GND 共地）；幅度 ≤ ±10V（±10V 量程时峰值不得超过 ±10V，Vpp≤20V）；观察用建议 ≤100kHz（1MSPS 无滤波下兼顾残余噪声与幅度）。

1. 电源：模块单 +5V（取 J11 PIN2），板上 5.8V→5V/3.3V 生成 VDRIVE；接口 3.3V 兼容，直接接 BANK35 安全（模块数字口 100R 限流+上下拉）。
2. **STBY(F=G19) 必须高**（正常模式；模块已有上拉，FPGA 复位后置 1 更稳）。
3. 硬件模式（推荐起步）：OS[2:0]=000（无滤波）、SER(C=F20) 置低=并行、CONV(E=G20) 上升沿启动、BUSY(L=M19) 下降沿后拉低 CS/RD 依次读 8 通道、DB[15:0] 16bit 二进制补码（0V≈0x0000，-10V≈0x8000，+10V≈0x7FFF）。
4. 软件模式（改量程/滤波/串行）：需要 WR(H=J18) 独立并拆模块 H5 跳线帽，本项目第二阶段再做。

## 7. XDC 文件说明（同目录 `ad7606c_j11.xdc`）

`.xdc` = **Xilinx Design Constraints**（Xilinx 设计约束文件），Vivado 工程里负责三件事：
1. **引脚绑定（PACKAGE_PIN）**：把 RTL 端口名（如 `adc_os[1]`）绑到 FPGA 封装引脚（如 F17）；
2. **电气标准（IOSTANDARD）**：声明 IO 电平（本项目 LVCMOS33，匹配 J11 BANK35=3.3V）；
3. **时序约束（create_clock/set_false_path 等）**：告诉工具时钟频率、跨时钟域例外，供布线优化（本文件暂只含 1/2，时序约束待工程创建时补充）。

本文件即上表第 3 节的机器化表达，Vivado 工程创建后直接 `add_files` 引用；它也复用了官方 AN706 XDC 的写法风格（`set_property PACKAGE_PIN … [get_ports …]`）。
