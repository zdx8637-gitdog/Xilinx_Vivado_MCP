# AD7606C-16 模块物理事实卡（板卡包附属资产）

> 性质：**黑盒可见的公开物理事实**（板卡包 = 唯一公开事实源）。
> 器件：凌智电子 AD7606C-16 8 通道 1 MSPS 并行 ADC 模块 V1.3（丝印 `16Bit@1MSPS_ADC V1.3`，芯片 ADI AD7606C-16）。
> 连接：模块 J2（2×17 排针）→ 40pin 转接板 → ALINX AX7020 **J11** 扩展口。
> 映射状态：**FROZEN（用户确认）**——机器可读版 `adc_ad7606c_pinmap.json`（板卡包根目录）、XDC 见 `docs/boardinformation/ad7606c_j11.xdc`。
> 完整推理与出处：`docs/boardinformation/ACM7606C_to_AX7020_pinmap.md`。

## 1. 接口信号（J11，共 24 线，LVCMOS33 / BANK35=3.3V）

| 类别 | 信号 | 方向（对 FPGA） | 说明 |
|---|---|---|---|
| 滤波配置 | OSI0/OSI1/OSI2 | 输出 | 过采样/滤波档位；硬件模式置 000=无滤波 |
| 接口模式 | SER | 输出 | 低=并行，高=串行（本项目用并行=低） |
| 转换启动 | CONV | 输出 | **上升沿启动全部通道转换** |
| 待机 | STBY | 输出 | **正常模式必须为高**（模块已有上拉） |
| 复位 | RESET | 输出 | 复位（有效极性以 datasheet 为准） |
| 寄存器写 | WR | 输出 | 软件模式用；硬件模式可置高/悬空 |
| 读控制 | CS_N / RD | 输出 | **BUSY 下降沿后：CS 拉低、RD 脉冲逐通道读取** |
| 首通道指示 | FRSTD | 输出 | 通道 1 数据窗口指示 |
| 忙指示 | BUSY | 输入 | 转换期间为高，**下降沿=数据就绪** |
| 数据总线 | DB[15:0] | 输入 | 16 位**二进制补码**，并行读出 |

## 2. 硬件模式读时序（本项目采用）

1. OS[2:0]=000、SER=0（并行）、STBY=1；
2. **CONV 上升沿**启动全部 8 通道同步转换 → BUSY 变高；
3. **BUSY 下降沿**后：CS 拉低，RD 脉冲依次读出通道 1~8 的 DB[15:0]（FRSTD 标识通道 1 窗口）；
4. 下一轮 CONV 开始新周期。
   精确电气时序（t_CONV、t_ACQ、RD 脉冲宽度、建立/保持）**以本目录 ADI 数据手册为准**。

## 3. 数据格式与量程

- 编码：**16 位二进制补码**；0V ≈ 0x0000；满量程负端 ≈ 0x8000、正端 ≈ 0x7FFF。
- 量程由模块 **J1 跳帽**选择（硬件模式）：
  - ±10V 档：1 LSB = 20V/65536 ≈ **305.18 µV**；
  - ±5V 档：1 LSB = 10V/65536 ≈ **152.59 µV**（**本项目建议此档**，覆盖 ±3.3V 输入）。
- 基准 **J3 跳帽**：1–2 短接 = 内部 2.5V 基准（推荐）；2–3 = 外部基准（由 pin4 VREF 注入精密 2.5V）；pin5 = GND。
- 输入：8 通道差分/单端（V1±~V8±，270R 限流 + ±21V 钳位）；单端接法：信号源→Vx+，信号源地→Vx-（或与 GND 共地）；幅度不得超过所选量程。
- 本项目单通道：**使用通道 1（V1±）**，其余通道照读或忽略。

## 4. 供电

模块单 +5V 供电：由 J11 PIN2（+5V）/ PIN1（GND）经转接板馈入；模块板上自生成 3.3V（VDRIVE）。无需外接电源。
