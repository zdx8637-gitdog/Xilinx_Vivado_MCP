# S2 — 带宽 / 资源预算（Bandwidth & Resource Budget）

> 输入: 物理事实 + 需求指标 | 输出: 带宽预算表 + PL 资源占用预估

## 职责

把需求指标换算成可验证的预算数字：数据速率、帧率/采样率档位、吞吐上限；
对照板卡 PL 资源上限（如 53,200 LUT / 106,400 FF / 140 BRAM36 / 220 DSP48E1）
做资源占用预估。**全部换算由智能体自主完成**，推导式写入预算表。

## 输出

| 预算项 | 推导式 | 结论 |
|--------|--------|------|
| 链路速率 | 由需求指标与物理事实推导 | `<BUDGET_RATE>` |
| 吞吐上限 | 对照接口带宽上限 | `<BUDGET_CEILING>` |
| 资源占用 | 按架构粗估（LUT/FF/BRAM/DSP） | `<BUDGET_RESOURCES>` |
| DDR / 高速口余量 | 对照板卡内存与高速口带宽 | `<BUDGET_MEMORY>` |

## 智能体自主决策范围

- 全部换算与档位推导（如 UART 上行速率 → 最大采样率/帧率）；
- 档位超限时的降档方案（写进 S4 提案）。

## 用户必须提供的物理事实

- 目标档位偏好（可选，只拍「档位/取舍」，不拍工程细节）。

## 失败恢复入口

| 症状 | 动作 |
|------|------|
| 预算超限 | 回 S3 降档，或提出物理路径变更（如换用更高带宽接口） |
| 需求指标缺失 | 返回 S0 列出缺失项 |

## 涉及的工具类别

- domain query（只读证据）：`platform_list_ips`、`pl_query_*`、`ps_get_bsp_status` 等；
- 无任何 command / set 副作用。
